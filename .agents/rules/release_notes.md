# Quy tắc ghi chú bản phát hành (Release Notes)

Khi tạo Release trên GitHub hoặc cập nhật changelog trong `version.json`:
- **Chỉ ghi nội dung dành cho người dùng cuối (User-facing)**: Tập trung vào tính năng mới, thay đổi giao diện, cải thiện trải nghiệm sử dụng sau khi đã biên dịch.
- **Không đề cập code backend**: Tuyệt đối không ghi các chi tiết kỹ thuật nội bộ (tên hàm, tên biến, tên file code C++, refactor backend, database schema nội bộ...).
