🔌 Cắm TrimUI Brick (đang bật, chế độ USB = ADB) vào laptop. Chỉ cần tải 1 file dưới đây rồi double-click — nó tự tải adb, tải bản RomCloud mới nhất, đẩy vào máy, bung, cấp quyền. Xong rút cáp là dùng.

🪟 TẢI BẢN WINDOWS 🍎 TẢI BẢN MAC

Windows lần đầu cần driver USB 1 lần: mở zadig.akeo.ie, chọn thiết bị Android/TrimUI → Install WinUSB. Mac mở file .command lần đầu: chuột phải → Open.

Cách 2: cài ngay trên trình duyệt (Chrome/Edge)

Không tải gì về máy. Nếu báo lỗi cổng USB: tắt hết adb/driver đang giữ cổng, eject ổ đĩa Brick nếu đang hiện, tải lại trang rồi bấm 1 lần duy nhất.

  1. Kết nối máy: bấm nút bên dưới, cửa sổ trình duyệt hiện lên thì chọn TrimUI / Android device → Connect.

    Chưa kết nối.
  2. Cài RomCloud mới nhất: web tự tải bản mới nhất từ GitHub rồi đẩy vào thẻ nhớ, bung ra, cấp quyền, xong báo DONE.
