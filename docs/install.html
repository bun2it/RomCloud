🔌 Cắm TrimUI Brick (đang bật) vào laptop bằng cáp USB, dùng trình duyệt Chrome hoặc Edge mở trang này. Chỉ bấm các nút theo thứ tự — web tự làm hết.
  1. Kết nối máy: bấm nút bên dưới, cửa sổ trình duyệt hiện lên thì chọn TrimUI / Android device → Connect.

    Chưa kết nối.
  2. Cài RomCloud mới nhất: web tự tải bản mới nhất từ GitHub rồi đẩy vào thẻ nhớ, bung ra, cấp quyền, xong báo DONE.
