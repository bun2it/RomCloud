Trang chủ
🔌 Cắm TrimUI Brick (đang bật, chế độ USB = ADB) vào laptop, mở trang này bằng Chrome/Edge. Chỉ bấm 2 nút dưới đây — web tự tải bản mới nhất, đẩy vào máy, bung, cấp quyền. Không tải gì về laptop.
  1. Kết nối máy: bấm nút bên dưới, cửa sổ trình duyệt hiện lên thì chọn TrimUI / Android device → Connect.

    Chưa kết nối.
  2. Cài RomCloud mới nhất: web tự tải bản mới nhất từ GitHub rồi đẩy vào thẻ nhớ, bung ra, cấp quyền, xong báo DONE.

[nhật ký]
Mở trang bằng Chrome/Edge để dùng WebUSB.

Nếu báo lỗi cổng USB: eject ổ đĩa Brick nếu đang hiện trên máy, tắt adb khác đang chạy, tải lại trang rồi bấm 1 lần duy nhất.

Cách dự phòng: tải file về máy

Khi web ở trên không dùng được. Tải 1 file theo hệ điều hành rồi double-click, nó tự làm hết.

🪟 BẢN WINDOWS 🍎 BẢN MAC

Windows lần đầu cần driver USB 1 lần: mở zadig.akeo.ie, chọn thiết bị Android/TrimUI → Install WinUSB. Mac mở file .command lần đầu: chuột phải → Open.
